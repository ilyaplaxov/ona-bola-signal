## 2а. Сигнал от пациентки (Telegram-бот)

Беременная сама сообщает в поликлинику своего района об осложнении или о начале родов. Ментор этого не просил, идея наша. Уточнить у ментора пока не успели, поэтому ниже — наши допущения. Проверить их при первой возможности.

**Зачем.** Сейчас сигнал идёт только от врача, и только во время визита. Бот даёт сигнал от самой женщины между визитами. Telegram в Узбекистане есть почти у всех: не нужно ставить приложение и придумывать пароль.

### Как работает

1. **Привязка.**
   - В карточке пациентки врач нажимает «Подключить Telegram» и получает одноразовый код на 24 часа и ссылку `t.me/<бот>?start=<код>` (плюс QR).
   - Пациентка открывает ссылку, бот показывает короткий текст согласия (раздел «Допущения»), она нажимает «Согласна» — карта привязана.
   - Ни ФИО, ни телефон бот не спрашивает.
2. **Меню бота — только кнопки, без свободного текста.**
   - 13 тревожных признаков из протокола: АУ с. 30, в коде уже есть — `data-pack/protocol-data.ts`, `ALARM_SIGNS`. Список не придумываем.
   - «Начались роды».
   - «Другой вопрос — прошу перезвонить».
3. **Ответ бота на тревожный признак — сразу:**

   > Немедленно обратитесь за медицинской помощью. Если состояние тяжёлое — звоните 103. Ваш врач получил сигнал.

   Слова «немедленно обратиться за медицинской помощью» взяты из протокола (с. 30). Бот не ставит диагноз и не советует лечение.

4. **В реестре — новый тип оповещения «Сигнал пациентки».**
   - Получают её врач и патронажная медсестра.
   - Виден в списке алертов и на дашборде с пометкой «от пациентки».
   - Кнопки реакции: «Связались», «Вызвана на приём», «Направлена в стационар».
   - Если за 30 минут никто не отметил реакцию, сигнал видит руководитель.
5. **Зону сигнал сам не меняет.** Врач связывается с пациенткой и, если признак подтвердился, отмечает его в форме визита. Дальше решает Risk Engine. Правило «тревожный признак → красная зона» (пункт 6 в `data-pack/README.md`) добавляем, только если ментор подтвердит.
6. **Запасной вход без Telegram** — страница `/signal` на сайте: тот же код, те же кнопки, крупные, для телефона. Она же страхует демо, если с Telegram что-то пойдёт не так.
7. **Языки бота** — узбекский по умолчанию и русский, по языку Telegram пациентки, с переключателем.

### Допущения (проверить у ментора)

| Вопрос                                 | Допущение сейчас                                                                                                                       | Почему так                                                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Кто получает сигнал ночью и в выходные | Её врач и медсестра. Экстренную помощь бот сразу направляет в 103.                                                                     | Поликлиника не дежурит круглосуточно. Бот не должен создавать впечатление, что ночью сигнал кто-то читает. |
| Куда сообщать о начале родов           | Бот: «Звоните 103 или езжайте в роддом». Врачу — сигнал для сведения.                                                                  | Роды принимает роддом, а не поликлиника.                                                                   |
| Срок реакции                           | 30 минут, потом сигнал видит руководитель                                                                                              | Это настройка, а не клиническое правило. Меняется одной константой.                                        |
| Меняет ли сигнал зону                  | Нет, только после подтверждения врачом                                                                                                 | Движок работает на данных, проверенных медиком.                                                            |
| Согласие                               | При привязке: «Ваш сигнал увидит ваш врач. Сообщения проходят через Telegram. Бот не заменяет скорую помощь — 103.» Кнопка «Согласна». | Telegram — внешний сервис. Это к критерию S4.                                                              |

### Приватность и техника

- В сообщениях бота нет диагнозов, зон и результатов анализов.
- Бот хранит только связку «Telegram ID ↔ карта пациентки».
- В аудит пишется: сигнал получен (какой признак), кто и когда отметил реакцию.
- Бот сам опрашивает Telegram (long polling): публичный сервер не нужен, работает с ноутбука.
- Bot API вызывается через `fetch`, без новых зависимостей.
- Токен — в `backend/.env` (`TELEGRAM_BOT_TOKEN`), в git не попадает. Без токена бот выключен, остальное работает.

### Сценарий на демо (30 секунд)

1. Пациентка на телефоне нажимает «Кровянистые выделения».
2. Бот сразу отвечает про 103.
3. У врача на ноутбуке появляется сигнал «от пациентки».
4. Врач нажимает «Связались».

Телефон показываем через камеру или запись экрана.

- **Перед каждым пушем:**

  ```bash
  npm run format && npm run typecheck && npm test
  ```

- **Миграции.** Только добавляем новые, старые не меняем. Создаёт только Участник 1.
- **Ключ Claude.** Только в `backend/.env`, в git не попадает. Без ключа приложение работает, ИИ-функции просто скрыты.
- **Данные.** Только синтетические. Никаких реальных пациенток, фото реальных документов и реальных ФИО.
- **ИИ.** Не ставит и не меняет зону, не ставит диагноз, не назначает лечение. Всё, что предлагает ИИ, подтверждает врач.
