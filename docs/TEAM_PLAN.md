## 3. Кто что делает

### Участник 1 — бэкенд и интеграции (есть Claude)

Владеет папками `backend/` и `shared/`. **Только он создаёт миграции** (иначе номера `0003_…` столкнутся).

1. **До 13:30 — контракты.** Zod-схемы и эндпоинты в `shared/`: вход и выход, текущий пользователь, направления, вложения, статус DIMED. Закоммитить и отправить в `main`, чтобы Участник 2 мог строить экраны.
2. **Авторизация:**
   - пароль хранится как хеш (`node:crypto` scrypt, без новых зависимостей);
   - сессия в httpOnly cookie;
   - вместо `middleware/demo-actor.ts` — middleware сессии, `requireActor` остаётся с тем же смыслом;
   - демо-аккаунты в сиде;
   - запись в аудит при входе и неудачной попытке входа.
3. **Права по матрице** из раздела 2: проверка на сервере в каждом маршруте, а не только скрытие кнопок.
4. **Направления:** таблица, API, аудит, оповещение специалисту (как сейчас алерты).
5. **Вложения:**
   - файлы на диске в `backend/uploads/` (в `.gitignore`), метаданные в БД;
   - проверка типа и размера;
   - аудит без имени файла (в имени могут быть персональные данные).
6. **DIMED:** таблица-очередь отправки, заглушка-приёмник, статус в API.
7. **ИИ читает документ** (P1): PDF или фото заключения → черновик измерений, как у `analyze-note`.
8. Тесты на каждое, `docs/DECISIONS.md`, `docs/HANDOVER.md`.

## 5. Правила совместной работы

- **Доступ к репозиторию.** Владелец добавляет двоих в коллабораторы: GitHub → `ona-bola-signal` → Settings → Collaborators. Нужны их логины на GitHub.
- **Ветки.**
  - У каждого своя ветка: `feat/auth-backend`, `feat/ui-redesign` и так далее.
  - Сливаем в `main` небольшими кусками.
  - Перед слиянием — `git pull --rebase origin main`.
- **Кто какие папки трогает:**
  - Участник 1 — `backend/` и `shared/`;
  - Участник 2 — `frontend/` и `e2e/`;
  - Участник 3 — `docs/` и `data-pack/samples/`.
- **Перед каждым пушем:**

  ```bash
  npm run format && npm run typecheck && npm test
  ```

- **Миграции.** Только добавляем новые, старые не меняем. Создаёт только Участник 1.
- **Ключ Claude.** Только в `backend/.env`, в git не попадает. Без ключа приложение работает, ИИ-функции просто скрыты.
- **Данные.** Только синтетические. Никаких реальных пациенток, фото реальных документов и реальных ФИО.
- **ИИ.** Не ставит и не меняет зону, не ставит диагноз, не назначает лечение. Всё, что предлагает ИИ, подтверждает врач.
